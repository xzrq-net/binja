# Index dataclass fields in api members and api show

Observed 2026-09-13 by a cold trial subject (Fable) during the guide
compression review: `api members ConstantPointerRegisterValue` lists only the
two classmethods inherited from `RegisterValue`; the dataclass fields (`value`,
`type`, `offset`) are absent, and `api show RegisterValue` prints just
`RegisterValue()` with a source:line pointer, no docstring or fields. The
guide's claim that `api members CLASS` establishes membership is therefore
false for dataclasses. The guide now carries a "though not dataclass fields"
clause; drop it once the index covers them.

The index builder is under `binja/` (see `api_index` tests). Dataclass fields
are available via `dataclasses.fields()` or `__annotations__` at index time.

Closed: Public annotated class attributes indexed as field records; members and show render them with owners; guide clause dropped.
