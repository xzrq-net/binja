# Size result retention by time or bytes instead of 64 records

At the stress trial's observed 33 calls/s, the 64-finished-result window
covers about two seconds. After a 100-call loop the subject's earlier analysis
results were already `output_pruned`, so it had to copy every result to disk
immediately and treat the tool as write-once. Small results are cheap to keep;
consider retaining by total bytes (for example 64 MiB) and age rather than
count, or offering a pin/export. Keep artifact directories bounded.
