# Add whole-database text and constant search

bn has `search text` (rendered HLIL/MLIL/LLIL/disasm lines by substring or
regex) and `search constant` (IL instructions containing an integer), both with
a result cap and a time budget that report incomplete coverage. They locate
code before a function name is known.

Parked until a trial or real task needs it: a Python loop over `bv.functions`
covers small binaries, and the hard part is honest bounding (skipped functions,
timeout, cap) rather than the search itself. When picked up: reuse the 5bkxzv
output contract and never present a capped search as complete coverage.
Byte-pattern search with nibble wildcards over `bv.search` has the same
shape and could ride along.
